# Criterios editoriales canónicos — El Relato

Fecha de fijación: 2026-09-20

## 1. Nombres propios
- El griego materializado desde SBLGNT determina la identidad textual.
- La forma española se normaliza tomando como referencia principal RVR1960 y NVI.
- Si RVR1960 y NVI divergen por una diferencia de base textual, se elige la forma española que corresponda a la lectura SBLGNT usada por el proyecto.
- La misma persona/nombre debe conservar una forma española estable dentro de El Relato, salvo que la diferencia del griego sea textualmente significativa.
- Ejemplos: Abraham, Obed, Isaí, Rahab; en Lc 3, formas críticas como Josec, Yodá y Yojanán cuando correspondan al griego base.

## 2. Expresiones bíblicas tradicionales
- Se conservan cuando representan una imagen, metáfora o término real del griego y aportan contenido semántico/teológico.
- Se modernizan sólo los arcaísmos españoles que no agregan significado.
- Ejemplo de conservación deliberada: "cuerno de salvación".

## 3. Variantes textuales
- El texto principal sigue estrictamente la lectura griega SBLGNT materializada para el proyecto.
- Las variantes conocidas se documentan en notas/auditoría; no se mezclan silenciosamente con el texto principal.

## 4. Duplicados estructurales
- Si dos filas tienen la misma referencia, mismo griego y no cumplen una función narrativa distinta, se consideran un error de ensamblado/referencia.
- Deben corregirse en BOOK/capa estructural, conservando trazabilidad del cambio.
- No se altera SOURCE para resolver un problema de BOOK.

## 5. Microsegmentos y ensamblado
- Los segmentos a/b/c mantienen trazabilidad atómica al griego.
- Si el ensamblado produce una oración rota o artificial, puede recomponerse en BOOK para recuperar una oración natural en español.
- Las referencias atómicas se preservan internamente.
- SOURCE nunca se modifica para encubrir un problema de ensamblado de El Relato.

## Jerarquía de autoridad
1. SBLGNT materializado / testigos del proyecto.
2. Análisis léxico, morfológico y sintáctico.
3. Contexto inmediato y ensamblado de El Relato.
4. RVR1960/NVI para forma española de nombres propios y contraste de uso.
5. Otras traducciones sólo como referencia secundaria.

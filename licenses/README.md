# Licencias y permisos

Este directorio conserva evidencia documental de las licencias, permisos y condiciones de uso de las fuentes preservadas por El-Relato.

## Distinción de estados

- `declared_by_owner`: el titular del repositorio declara contar con permiso/licencia, pero la evidencia todavía no fue archivada aquí.
- `evidence_archived`: existe documento o referencia verificable dentro del repo.
- `public_license`: la licencia pública está identificada y archivada/referenciada.
- `needs_review`: requiere revisión antes de redistribución o publicación.

El repositorio es privado, pero igualmente conservamos esta capa para que el corpus sea auditable si alguna vez cambia su modalidad de uso.

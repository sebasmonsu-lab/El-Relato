# Manuscritos núcleo

Este directorio registra y preserva las fuentes manuscritas utilizadas por El-Relato.

Cada testigo debe conservar:
- identificador Gregory–Aland;
- Evangelio(s) y pasajes conservados;
- datación;
- institución custodiante;
- URL pública original;
- copia local cuando esté disponible;
- fecha de captura;
- checksum de cada archivo preservado;
- notas sobre transcripción y variantes.

El registro máquina-legible se encuentra en `data/manifests/manuscripts.json`.
